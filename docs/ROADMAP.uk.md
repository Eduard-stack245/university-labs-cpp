# Плани розвитку

[English](ROADMAP.md) | **Українська**

Мої плани й ідеї на наступні кроки. Примітки до наявного коду: [NOTES.uk.md](NOTES.uk.md).

## Зроблено
- **[random-toolkit](../projects/random-toolkit)** - чотири генератори з ASD як рушії, сумісні зі std, тестер хі-квадрат і `BasicRandom<Engine>`.
- **[random-class](../projects/random-class)** - `NextBool`, `NextGaussian`, `Shuffle`, `Choice` і власні тести (старий API не змінено).
- **[sorting-algorithms](../projects/sorting-algorithms)** - тести, що самі перевіряють результат (знайшли й виправили три помилки), і бенчмарк із виводом у CSV.
- **[graph-algorithms](../projects/graph-algorithms)** - `Graph` (матриця) і `SparseGraph` (списки суміжності, черга з пріоритетом, Краскал), перевірені проти Краскала і Флойда-Воршелла.
- **[records-database](../projects/records-database)** - один клас `Table` з типізованими стовпцями, CSV, пошуком у UTF-8, сортуванням, статистикою, відсортованим `Index` і меню.
- **[textstat](../projects/textstat)** - консольна статистика тексту, що розуміє UTF-8.
- **[vector-class](../projects/vector-class)** - `Vector<T>` з правилом п'яти, ітераторами та безпекою щодо винятків.

## Далі
### Набір алгоритмів
- власний компаратор для сортувань; бінарний пошук і приклади рекурсії (`lab13_*`) як функції бібліотеки;
- один спільний запускач тестів (Catch2 / GoogleTest) замість невеликих перевірок, написаних вручну;
- графи: орієнтовані графи, читання `SparseGraph` зі списку ребер, експорт `--dot` для Graphviz.

### Набір випадкових чисел
- більше статистичних тестів (тест серій, послідовна кореляція) і пошук періоду;
- потоколокальний рушій для `Random`.

### База записів
- оновлювати індекс при `add`, індекси за кількома стовпцями, схема з заголовка CSV, експорт у JSON.

### Менші проєкти
- `textstat`: вивід у CSV, кілька файлів в одному звіті.
- `vector-class`: власний клас ітератора, `insert` / `erase` діапазонів, бенчмарк `push_back` проти `std::vector`.
- `utility-payments`: читати тарифи з CSV/JSON замість шести жорстко заданих пунктів, зберігати історію.
