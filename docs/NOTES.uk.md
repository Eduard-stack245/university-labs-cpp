# Примітки до коду

[English](NOTES.md) | **Українська**

Ці лабораторні я писав під час навчання у кількох рішеннях Visual Studio (і двох проєктах Code::Blocks).
Щоб репозиторій збирався в MSVC, GCC і Clang, у кожному файлі я змінив таке:

| Старий код | Новий код |
|---|---|
| `system("pause")` | `lab::pause()` |
| `system("cls")`, `clrscr()` | `lab::clear_screen()` |
| `system("chcp 1251")`, `SetConsoleCP(1251)`, `SetConsoleOutputCP(1251)`, `setlocale(LC_ALL, "Russian")` | `lab::init_console()` (консоль UTF-8 у Windows) |
| `#include <Windows.h>` (потрібен лише для рядків вище) | `#include "lab_compat.h"` |
| `#include <Math.h>` (велика M - не працює на Linux) | `#include <math.h>` |
| `scanf_s`, `printf_s`, `fopen_s`, `errno_t` | стандартні функції / невеликі обгортки в `lab_compat.h` |
| `boolean`, `void main()` | `bool`, `int main()` |
| `"\r\n"` у printf | `"\n"` |
| порожні літерали `u8""` (помилка в C++20, де рядки `u8` стали `char8_t`) | `""` |
| суміш Windows-1251 і UTF-8 у файлах | усе в UTF-8 |
| шляхи `C:/temp/...` | файли в робочій папці (приклади даних додано) |

Усі коментарі тепер англійською; текст, який друкують програми, залишився російською / українською.

## Помилки, які я виправив (позначені в коді `FIX:`)
- `lab05_02` - відповідь зберігалася в однобайтовому `boolean`, а читалася через `%d`.
- `lab05_03` - розбір дати читав за межами буфера; кириличні рядки не вміщувалися в буфери, коли стали UTF-8.
- `lab05_07` - `float` друкувався через `%i`.
- `utility_payments` - зсув індексу тарифу на одиницю (пункт меню 6 читав за межею масиву); буфери замалі для UTF-8.
- `array_multiples_of_3` - цикл `i <= 15` для масиву з 15 елементів.
- `dynamic_array` - масив виділявся до того, як був відомий його розмір.
- `asd_lab3_generators`, `asd_lab4_chi_square` - переповнення знакового цілого (невизначена поведінка) у формулі лінійного конгруентного генератора.
- `test_random` - `Calculation[20]`, але записувалося 25 значень.
- `tree_print` - описки (`1` замість `l`), код не компілювався.
- `lab11_12` - заголовок `My_Lb.h` загубився; я переписав його за `My_Lb.cpp`.
- `sorting-algorithms` - `quick_sort`, `counting_sort` і `radix_sort` падали на порожньому вході; `radix_sort` використовував звільнену пам'ять із від'ємними числами (знайдено тестом `sort_tests`).

## Навмисні навчальні приклади
- `lab06_05`, `lab06_08` - `lab06_11` виконуються нескінченно (зупиніть через Ctrl+C).

## Додаткові виправлення
- Для словника та бази записів використовується спільний модуль UTF-8:
  пошук не залежить від регістру української кирилиці.
- Файлова лабораторна аналізує всі рядки тексту, а не лише останній.
- Тест хі-квадрат порівнює частоти в інтервалах; генератор BBS
  використовує відповідні прості числа й не виділяє тимчасову пам’ять.

## Чого немає в репозиторії
- Дублікатів: одні й ті самі програми існували двічі (папка з окремими файлами та її копія) і як окремі рішення Visual Studio; я залишив по одній копії.
- `Lb5_5` як рішення - це був лише шаблон «Hello World» Visual Studio; справжній `Lb5_5` лежить у `lab05-branching`.
- Старішої чернетки `lab07_08_02b` (цикл, який ніколи не виконується) і копії тексту словника без формату `|`.
- Усіх залишків збірки (`.vs`, `Debug`, `x64`, `.user`, ...).

## Як це перевірялося

CMake/CTest перевіряє зареєстровані тести з підготовленим введенням та тести алгоритмів.
Тести з AddressSanitizer/UBSan виконуються на Linux. Деякі інтерактивні програми
не мають автоматичних тестів. Windows і macOS перевірятимуться після публікації через GitHub Actions.

## Організація коду та навчальні завдання

- Кожна початкова вправа залишається окремою програмою. Невеликі приклади
  навмисно залишено процедурними, щоб не приховувати цикли, масиви та рекурсію
  за зайвими класами.
- Бібліотеки мають окремі тести, а інтерактивні вправи перевіряються
  прикладами введення та виведення. Успішна збірка сама по собі не доводить
  повну відповідність університетським завданням.
- У графовій роботі перевіряються номери вершин, файлові таблиці читають і
  записують єдиний формат із роздільником `;`, а перед використанням матриць
  перевіряються розміри й діапазони.
- Вправи з навмисно нескінченними циклами у `lab06-loops` не запускаються
  автоматично; їх слід переривати вручну.
