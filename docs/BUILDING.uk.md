# Як зібрати й запустити будь-який проєкт

[English](BUILDING.md) | **Українська**

Кожен проєкт у `projects/` має власний `CMakeLists.txt`, тому кроки для всіх однакові. Потрібні компілятор C++ і CMake 3.10 або новіший
(Visual Studio 2019+ уже містить обидва).

## Варіант 1 - Visual Studio 2019 / 2022 (найпростіше на Windows)
1. `File -> Open -> Folder...`
2. Виберіть **папку одного проєкту** (наприклад, `projects/random-class`) або корінь репозиторію, щоб побачити всі проєкти в одному списку.
3. Зачекайте, поки в рядку стану з'явиться повідомлення, що генерація CMake завершена.
4. На панелі інструментів виберіть програму (наприклад, `random_demo.exe`) і натисніть **Ctrl+F5** (запуск без налагодження, консоль не закривається).

## Варіант 2 - Visual Studio Code
Встановіть розширення *C/C++* та *CMake Tools*, відкрийте папку, натисніть `Ctrl+Shift+P` -> **CMake: Configure**, потім **CMake: Build**
і **CMake: Run Without Debugging**.

## Варіант 3 - CLion
`File -> Open`, виберіть папку. CLion сам знайде CMake.

## Варіант 4 - Термінал (Windows, Linux, macOS)
З папки проєкту (або з кореня репозиторію, щоб зібрати все):

```
cmake -S . -B build
cmake --build build --config Release
```

Запуск програми:

| Система | Команда |
|---|---|
| Linux / macOS | `./build/<програма>` |
| Windows (генератор Visual Studio) | `build\Release\<програма>.exe` |

Запустити всі демо як тести: `ctest --test-dir build -C Release`

## Варіант 5 - Без CMake
Для проєктів лише з кількох файлів:

```
g++ -std=c++17 -o program main.cpp Other.cpp
```

(Використовуйте стандарт, указаний у README проєкту.)

## Типові проблеми
| Проблема | Що робити |
|---|---|
| Помилка про `if constexpr` / `is_integral_v` / C++17 | Компілятор застарілий або не задано стандарт. Оновіть його або додайте `-std=c++17`. |
| Вікно консолі одразу закривається | Запускайте через **Ctrl+F5**, а не F5. |
| Дивні символи замість російського/українського тексту | Збережіть вихідний файл у UTF-8. CMake-файли вже передають `/utf-8` для MSVC. Переконайтеся, що термінал теж у UTF-8 (`chcp 65001` у Windows). |
| `conio.h`, `windows.h`, `system("pause")` не знайдено на Linux/macOS | Лабораторна лише для Windows; про це сказано в README проєкту. |
| `cmake` не знайдено | Встановіть з https://cmake.org/download/ або скористайтеся компонентом «C++ CMake tools» в інсталяторі Visual Studio. |
| Старий `.sln` з Visual Studio пропонує «Retarget» | Це нормально: оригінал зроблено для старішого набору інструментів. Натисніть OK або просто користуйтеся CMake. |
