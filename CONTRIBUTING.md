# Contributing / Участь у проєкті

**English** | [Українська](#українська)

## English
Thank you for your interest! This repository is a collection of my C++ university labs and the libraries that grew out of them.
Bug reports, questions and pull requests are welcome.

- **Found a bug?** Open an issue and tell me the project, your system, the compiler and the steps to reproduce it.
- **Want to change something?** Fork the repository, make your change in a branch and open a pull request.
- **Adding a project?** Follow [docs/ADDING_A_PROJECT.md](docs/ADDING_A_PROJECT.md).

Please keep to these rules (the build check on GitHub tests most of them):
1. C++17 and CMake; every program builds on Windows, Linux and macOS.
2. Sources are UTF-8, comments are in English.
3. A program that reads the keyboard has a sample input in `tests/` (see `INPUT` in `add_lab`); libraries get self-checking tests.
4. No build output in git (`.gitignore` takes care of it - check `git status`).
5. By contributing you agree that your code is published under the [MIT license](LICENSE).

## Українська
Дякую за інтерес! Цей репозиторій - збірка моїх університетських лабораторних на C++ та бібліотек, що з них виросли.
Звіти про помилки, питання та pull request'и вітаються.

- **Знайшли помилку?** Створіть issue: вкажіть проєкт, систему, компілятор і кроки, щоб її відтворити.
- **Хочете щось змінити?** Зробіть fork, внесіть зміни в окремій гілці й відкрийте pull request.
- **Додаєте проєкт?** Дотримуйтесь [docs/ADDING_A_PROJECT.uk.md](docs/ADDING_A_PROJECT.uk.md).

Будь ласка, дотримуйтесь правил (більшість із них перевіряє автоматична збірка на GitHub):
1. C++17 і CMake; кожна програма збирається на Windows, Linux і macOS.
2. Вихідні файли в UTF-8, коментарі англійською.
3. Програма, що читає з клавіатури, має приклад вводу в `tests/` (див. `INPUT` в `add_lab`); бібліотеки мають тести, що самі перевіряють результат.
4. Жодних результатів збірки в git (`.gitignore` це враховує - перевірте `git status`).
5. Надсилаючи свій код, ви погоджуєтесь, що він публікується за [ліцензією MIT](LICENSE).
