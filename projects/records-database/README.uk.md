# records-database

[English](README.md) | **Українська**

Одна універсальна таблиця записів замість чотирьох копій тієї самої лабораторної:
[struct-tables](../struct-tables) (одяг, студенти), [file-tables](../file-tables) (те саме з файлами),
[dictionary](../dictionary) та база студентів `student_tree` у [binary-trees](../binary-trees).

| Файл | Що це |
|---|---|
| `Table.hpp` | `rdb::Table`: типізовані стовпці (текст / ціле / дійсне), `add`, `removeAt`, `find`, `sortBy`, `stats`, `loadCsv` / `saveCsv`, `print` |
| `Csv.hpp` | читання/запис CSV (роздільник `;`, лапки, розриви рядків усередині лапок) |
| `Index.hpp` | `rdb::Index`: відсортований індекс за одним стовпцем - точний збіг, пошук за початком (текст, кирилиця працює) і за діапазоном (числа) за O(log n + k); помічає, що таблиця змінилася |
| `Utf8.hpp` | нижній регістр для латиниці та кирилиці (зокрема українських літер), «містить» без урахування регістра, довжина в UTF-8 |
| `main.cpp` | `records_cli` - програма з меню |
| `records_tests.cpp` | `records_tests` - тести, що самі перевіряють результат |

## Програма з меню
```
records_cli [clothes | students | dictionary]        (за замовчуванням: clothes)
```
Дані читаються з `<назва>.csv` у робочій папці (приклади файлів додано, CMake копіює їх поруч із програмою):

| Набір | Стовпці | Приклад файлу |
|---|---|---|
| `clothes` | type, color, size (ціле), price (дійсне) | `clothes.csv` |
| `students` | surname, name, patronymic, math (ціле), physics (ціле) | `students.csv` |
| `dictionary` | word, description | `dictionary.csv` (60 записів лабораторної зі словником) |

Команди: **1** додати, **2** показати все, **3** пошук у стовпці, **4** сортувати за стовпцем, **5** видалити рядок, **6** статистика числового стовпця, **7** зберегти, **8** пошук через індекс (за початком для тексту, за діапазоном для чисел), **0** вихід.
Числа перевіряються під час додавання (`XL` у цілому стовпці відхиляється), числа сортуються як числа, а пошук не залежить від регістра - у тому числі для кирилиці.

Щоб використати інший вид записів, додайте схему в `makeTable` у `main.cpp` (список назв і типів стовпців); більше нічого змінювати не треба.

## Вимоги
Компілятор C++17 (MSVC 2019+, GCC, Clang) і CMake 3.10+.

## Збірка та запуск
```
cmake -S . -B build
cmake --build build
cd build && ./records_cli dictionary        # у Windows: build\Debug\records_cli.exe dictionary
./records_tests
```
Visual Studio: `File -> Open -> Folder...`, виберіть цю папку, оберіть програму на панелі інструментів, Ctrl+F5.

## Чим краще за лабораторні
- Пошук у словнику не залежить від регістра для кирилиці (у лабораторній в нижній регістр переводився лише ASCII).
- Вхідні дані перевіряються; неправильні дані дають повідомлення про помилку замість псування таблиці.
- CSV з лапками: поля можуть містити `;` і лапки. У лабораторних файли різних програм використовували різні роздільники.
- Відсортований індекс (ідея дерева студентів) для швидкого пошуку за початком і діапазоном; у тестах його порівнюють зі звичайним перебором на випадкових даних.
- Одна реалізація, покрита тестами, замість чотирьох майже однакових копій.

## Ідеї
- Оновлювати індекс при `add` замість перебудови; індекси за кількома стовпцями; кілька ключів сортування.
- Читати схему із заголовка CSV замість вшитої в код; експорт у JSON.
