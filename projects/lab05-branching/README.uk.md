# Лабораторна 5 - розгалуження (if / else)

[English](README.md) | **Українська**

Вправи першого семестру в стилі C: умови, кускові функції, квадратне рівняння.

## Програми

| Програма | Що робить | Оригінальний файл |
|---|---|---|
| `lab05_02` | Обчислює x, y, z для a = 0.1, b = 0.2, потім вибирає V1 або V2, порівнюючи введене x з y. Повторюється, доки не введено 0. | `Lb5_2.cpp` |
| `lab05_03` | Введіть дату (дд.мм.рррр) і отримайте день тижня, назву місяця та пору року. | `Lb5_3.cpp` |
| `lab05_04` | Кускова функція: y = x - 1 при x < -5, y = x^2 + 2 при x > 5, інакше «розв'язку немає». | `Lb5_4.cpp` |
| `lab05_05` | Кускова функція: y = x^3 - 2x при -20 < x < 0, y = x - x^2 при x > 5, інакше «розв'язку немає». | `Lb5_5.cpp` |
| `lab05_06` | Кускова функція з умовами на проміжки (x/2 + 5 на двох проміжках, x^2 + 1/x на двох інших). | `Lb5_6.cpp` |

| `lab05_09` | Головоломка: оператор «кома» і присвоєння всередині умов `if` - що буде надруковано? | `Lb5_9.cpp` |

## Вимоги

Компілятор C++17 (MSVC 2019+, GCC 7+, Clang 5+) і CMake 3.10+.

## Збірка та запуск

Visual Studio 2019/2022: `File -> Open -> Folder...`, виберіть цю папку, оберіть програму на панелі інструментів і натисніть Ctrl+F5.

Термінал:

```
cmake -S . -B build
cmake --build build
ctest --test-dir build -C Debug     # необов'язково: запускає кожну програму з прикладом вводу
```

Інші варіанти: [docs/BUILDING.uk.md](../../docs/BUILDING.uk.md).

## Примітки до коду

Я писав ці програми для Windows і Visual Studio. Щоб вони збиралися скрізь, я змінив таке:
- вихідні файли тепер у UTF-8 (раніше суміш UTF-8 і Windows-1251);
- `system("pause")`, `system("cls")`, `chcp 1251` та `SetConsoleCP` замінено на `lab::pause()`, `lab::clear_screen()`, `lab::init_console()` з [common/lab_compat.h](../../common/lab_compat.h);
- Microsoft-специфічні функції (`scanf_s`, `printf_s`, `boolean`, `void main`) замінено стандартним C++;
- логіка в іншому не змінена; місця, де довелося змінити поведінку, позначені в коді `FIX:`.
- `lab05_02` раніше зберігав відповідь «продовжити?» в однобайтовій змінній; тепер це `int`.
- `lab05_03`: розбір дати переписано через `sscanf` (стара версія читала за межами невеликого буфера); оригінальний вислів «Все надоело!!!» усе ще друкується.

Розв’язувач окремо обробляє `a = 0` і обчислює дискримінант у `double`, щоб уникнути переповнення цілих чисел.

У `lab05_06` збережено дробовий ввід (раніше `float` перетворювався на `int`). Прості числові вправи також перевіряють введення та уникають переповнення при піднесенні до квадрата.
