# graph-algorithms

[English](README.md) | **Українська**

Мінімальне остовне дерево за Примом і найкоротші шляхи за Дейкстрою як невеликий клас для повторного використання.
У лабораторних ASD [asd-graph-algorithms](../asd-graph-algorithms) була одна жорстко задана матриця 6x6; тут граф читається з файлу.

| Програма | Що робить |
|---|---|
| `graph_demo` | `graph_demo [файл] [початкова вершина]` - друкує остовне дерево та найкоротший шлях до кожної вершини (за замовчуванням: `graph6.txt`, вершина 1) |
| `sparse_tests` | тести `SparseGraph`, що самі перевіряють результат (див. нижче): ті самі відповіді, що й у матричних класів, на 300 випадкових графах, плюс ланцюжок із 200 000 вершин |
| `graph_tests` | тести, що самі перевіряють результат: Прим проти Краскала і Дейкстра проти Флойда-Воршелла на графі з лабораторної та 300 випадкових графах (зв'язних і ні), плюс перевірка вхідних даних |

`Graph.hpp` (лише заголовок):

```cpp
std::ifstream in("graph6.txt");
gx::Graph g = gx::Graph::fromMatrix(in);
auto mst = g.primMst();                       // mst.edges, mst.total, mst.connected
auto sp  = g.dijkstra(0);                     // sp.dist[v], sp.parent[v]
auto path = gx::Graph::pathTo(sp, 5, 0);      // вершини 0 -> ... -> 5
```

## SparseGraph - для великих графів
`SparseGraph.hpp` розв'язує ті самі задачі для розріджених графів: списки суміжності (пам'ять O(V + E) замість O(V^2)),
Дейкстра з чергою з пріоритетом (O((V + E) log V)) і алгоритм Краскала (сортування ребер + union-find).

```cpp
gx::SparseGraph s(200000);
s.addEdge(0, 1, 5);                       // неорієнтоване, вага > 0; паралельні ребра дозволені (перемагає найдешевше)
auto sp  = s.dijkstra(0);                 // той самий тип результату, що й Graph::dijkstra
auto mst = s.kruskalMst();                // остовний ліс, якщо граф не зв'язний (mst.connected == false)
auto s2  = gx::SparseGraph::fromGraph(g); // перетворення матричного графа
```
У тестах працює ланцюжок із 200 000 вершин; матричній версії для нього знадобилося б близько 160 ГБ.

## Формат файлу
```
6              <- кількість вершин
0 5 0 1 3 0    <- матриця суміжності, 0 = немає ребра; має бути симетричною з нульовою діагоналлю
5 0 1 0 7 0
0 1 0 0 5 4
1 0 0 0 2 0
3 7 5 2 0 10
0 0 4 0 10 0
```

## Вимоги
Компілятор C++17 (MSVC 2019+, GCC, Clang) і CMake 3.10+.

## Збірка та запуск
```
cmake -S . -B build
cmake --build build
./build/graph_demo
./build/graph_tests
./build/sparse_tests
```
Visual Studio: `File -> Open -> Folder...`, виберіть цю папку, оберіть програму на панелі інструментів, Ctrl+F5.

## Примітки
- На графі з лабораторної результати збігаються з оригінальними: вага остовного дерева 13, найкоротший шлях 1 -> 6 має довжину 10 (1-2-3-6).
- `Graph` зберігає прості матричні версії O(n^2) з лабораторних; `SparseGraph` - масштабована версія. Можливі наступні кроки: орієнтовані графи, читання `SparseGraph` зі списку ребер, експорт `--dot` для Graphviz.
