# textstat

[English](README.md) | **Українська**

Консольна утиліта, що друкує статистику текстового файлу або стандартного вводу. Виросла з вправ на рядки з
[text-analysis](../text-analysis) (слова непарної довжини, частоти літер, текст у дужках).

```
textstat [--top N] [файл ...]        без файлу або «-» читає стандартний ввід
textstat --help
```

Приклад (`sample.txt` додано):

```
== sample.txt ==
bytes 253, characters 182, lines 3
words 27, letters 138, digits 4
words of odd length 14, average word length 5.33, longest word: послідовність

most frequent words:
      2  the
      2  алгоритм
...
letter frequency (case-insensitive):
  а      8    5.8%  ##############################
...
text in parentheses:
  (для розв’язання задачі)
  (a very fast animal)
```

## Що вона показує
- байти, символи (для кирилиці це не одне й те саме!), рядки, слова, літери, цифри
- слова непарної довжини (завдання лабораторної), середню довжину слова, найдовше слово
- найчастіші слова та літери без урахування регістра (`Кіт`, `кіт` і `КІТ` - це одне слово)
- текст у дужках; вкладені дужки залишаються всередині зовнішньої групи; незбалансовані `(` / `)` виводяться як попередження

## Файли
| Файл | Що це |
|---|---|
| `TextStat.hpp` | бібліотека: декодування UTF-8, класи літер (латиниця, кирилиця, грецька), `ts::analyze(text)` повертає `Report` |
| `main.cpp` | консольна утиліта |
| `textstat_tests.cpp` | тести, що самі перевіряють результат (круговий обхід UTF-8, зламаний UTF-8, апострофи й дефіси у словах, вкладені дужки, ...) |

Слово - це послідовність літер і цифр; `'`, `’` і `-` належать слову, коли стоять між двома літерами
(`розв’язання`, `well-known`, `it's` - по одному слову). Крапка або кома завершує слово.

## Вимоги
Компілятор C++17 (MSVC 2019+, GCC, Clang) і CMake 3.10+.

## Збірка та запуск
```
cmake -S . -B build
cmake --build build
./build/textstat sample.txt
./build/textstat --top 20 < somefile.txt
./build/textstat_tests
```
Visual Studio: `File -> Open -> Folder...`, виберіть цю папку, оберіть програму на панелі інструментів. Щоб передати аргументи, скористайтеся
`Debug -> Debug and Launch Settings`; або запустіть `textstat.exe sample.txt` у терміналі з папки збірки.

## Примітки
- Літери розпізнаються для латиниці (з діакритикою), грецької та кирилиці; інші писемності (китайська, арабська, ...) рахуються як символи, але не як літери чи слова.
- Старі програми з лабораторних рахували байти `std::string`, що дає неправильні результати для кирилиці; тому текст спочатку декодується.

## Ідеї
- Вивід `--csv`, режими `--letters-only` або `--words-only`, читання кількох файлів в один звіт.
- Кількість речень і оцінка часу читання; список стоп-слів для «найчастіших слів».
