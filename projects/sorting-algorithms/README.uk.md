# Бібліотека алгоритмів сортування

[English](README.md) | **Українська**

Бібліотека C++ з одного заголовка: вісім алгоритмів сортування та кілька статистик масиву. Це був «двигун» лабораторної
Windows Forms `SortProg`; тут його винесено, щоб він збирався на будь-якій системі.

| Клас | Алгоритм |
|---|---|
| `InsertSort`, `BubbleSort`, `CocktailShakerSort` | прості сортування O(n^2) |
| `MergeSort`, `HeapSort`, `QuickSort` | сортування O(n log n) |
| `CountingSort`, `RadixSort` | сортування без порівнянь (лише `int`) |
| `ArrayProcessing` | випадковий масив, min, max, середнє, медіана, мода, копіювання, розворот |

| Програма | Що робить |
|---|---|
| `sorting_demo` (`main.cpp`) | сортує один випадковий масив кожним алгоритмом і перевіряє результат |
| `sort_tests` | тести, що самі перевіряють результат: кожен алгоритм проти `std::sort` на порожніх, маленьких, з великою кількістю дублікатів, випадкових і від'ємних входах; код виходу 1, якщо щось не так |
| `sort_benchmark` | таблиця часу: `sort_benchmark [--csv result.csv] [size ...]`, розміри за замовчуванням 1000 2000 4000 |

Приклад (одна машина з Linux, `-O2`, мілісекунди): на 20000 числах сортування вставками / бульбашкою / шейкером займають приблизно 640 / 1130 / 1010,
а злиттям / купою / швидке / порозрядне - 0.6-2, `std::sort` - близько 1. Для змістовних замірів збирайте у режимі Release.

```cpp
#include "SortingAlgorithms.hpp"
int a[5] = {5, 2, 9, 1, 7};
SortingAlgorithms::QuickSort<int>::quick_sort(a, 0, 4);
```

## Вимоги
Компілятор C++17 (MSVC 2019+, GCC, Clang) і CMake 3.10+.

## Збірка та запуск

```
cmake -S . -B build
cmake --build build
./build/sorting_demo
./build/sort_tests
./build/sort_benchmark 1000 10000 50000 --csv result.csv
```
Visual Studio: `File -> Open -> Folder...`, виберіть цю папку, Ctrl+F5.

## Примітки
- Оригінал: `SortProg/Sorting.cpp` (заголовок у файлі `.cpp`, коментарі у Windows-1251). Тепер UTF-8, названо `SortingAlgorithms.hpp`.
- Тести, які я додав, знайшли три справжні помилки в оригінальному коді, тепер виправлені й позначені `FIX:` у заголовку:
  `quick_sort`, `counting_sort` і `radix_sort` падали на порожньому вході, а `radix_sort` читав звільнену пам'ять, коли в масиві були від'ємні числа
  (тепер він зсуває значення, тож від'ємні числа працюють, поки `max - min` вміщується в `int`).
- `merge_sort(a, 0, n - 1)` не можна викликати з `n == 0`; `quick_sort` тепер до цього стійкий.
- Оригінальний інтерфейс WinForms лежить у [legacy-windows/sort-prog-winforms](../../legacy-windows/sort-prog-winforms).
- `main.cpp`, `sort_tests.cpp` і `sort_benchmark.cpp` додано пізніше - у самій лабораторній консольних програм не було.

Допоміжні функції статистики перевіряють порожній ввід, генерація масиву враховує обидві межі діапазону.
