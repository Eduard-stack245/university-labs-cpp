# Аналіз тексту

[English](README.md) | **Українська**

Рядки: підрахунок слів, частоти літер, текст у дужках, читання файлу та запис журналу.

## Програми

| Програма | Що робить | Оригінальний файл |
|---|---|---|
| `text_console` | Введіть рядок: рахує слова непарної довжини, друкує частоти літер, виділяє текст у дужках. | `Lb2_5_1.cpp` |
| `letter_frequency` | Введіть речення: скільки разів трапляється кожен символ і загальна частота повторень. | `Lb2_5_2.cpp` |
| `text_from_file` | Той самий аналіз, але текст читається з `words.txt`, а звіт іде в консоль і в `log.txt`. | `Lb2_8_1.cpp` |

## Вимоги

Компілятор C++17 (MSVC 2019+, GCC 7+, Clang 5+) і CMake 3.10+.

## Збірка та запуск

Visual Studio 2019/2022: `File -> Open -> Folder...`, виберіть цю папку, оберіть програму на панелі інструментів і натисніть Ctrl+F5.

Термінал:

```
cmake -S . -B build
cmake --build build
ctest --test-dir build -C Debug     # необов'язково: запускає кожну програму з прикладом вводу
```

Інші варіанти: [docs/BUILDING.uk.md](../../docs/BUILDING.uk.md).

Файли даних (`words.txt`) CMake копіює поруч із програмою; програми читають їх із робочої папки.

## Примітки до коду

Я писав ці програми для Windows і Visual Studio. Щоб вони збиралися скрізь, я змінив таке:
- вихідні файли тепер у UTF-8 (раніше суміш UTF-8 і Windows-1251);
- `system("pause")`, `system("cls")`, `chcp 1251` та `SetConsoleCP` замінено на `lab::pause()`, `lab::clear_screen()`, `lab::init_console()` з [common/lab_compat.h](../../common/lab_compat.h);
- Microsoft-специфічні функції (`scanf_s`, `printf_s`, `boolean`, `void main`) замінено стандартним C++;
- мету лабораторних збережено; виправлення описано в цьому README або в кореневому `CHANGELOG.md`.
- `text_from_file`: жорстко задані шляхи `C:/temp/` замінено файлами в робочій папці. Відома особливість: аналізується усі рядки файлу.

- `letter_frequency`: використовує контейнери, обробляє порожній ввід і підраховує повторення байтів. Для повноцінного аналізу UTF-8 використовуйте `textstat`.

Обидві програми використовують `TextAnalysisLab.hpp`; кириличні літери в UTF-8 враховуються як окремі символи.
