# ASD, лабораторні 3-4 - генератори псевдовипадкових чисел

[English](README.md) | **Українська**

Алгоритми та структури даних (ASD): чотири генератори псевдовипадкових чисел і тест хі-квадрат для оцінки їхньої якості.

## Програми

| Програма | Що робить | Оригінальний файл |
|---|---|---|
| `asd_lab3_generators` | Меню: Парк-Міллер, Л'Екюєр, лінійний конгруентний метод, Блюм-Блюм-Шуб. | `asd_lab3_generators.cpp` |
| `asd_lab4_chi_square` | Ті самі генератори плюс тест хі-квадрат (клас `test_random`), що перевіряє, чи схожі числа на випадкові. | `asd_lab4_chi_square.cpp` |

## Вимоги

Компілятор C++17 (MSVC 2019+, GCC 7+, Clang 5+) і CMake 3.10+.

## Збірка та запуск

Visual Studio 2019/2022: `File -> Open -> Folder...`, виберіть цю папку, оберіть програму на панелі інструментів і натисніть Ctrl+F5.

Термінал:

```
cmake -S . -B build
cmake --build build
ctest --test-dir build -C Debug     # необов'язково: запускає кожну програму з прикладом вводу
```

Інші варіанти: [docs/BUILDING.uk.md](../../docs/BUILDING.uk.md).

## Примітки до коду

Я писав ці програми для Windows і Visual Studio. Щоб вони збиралися скрізь, я змінив таке:
- вихідні файли тепер у UTF-8 (раніше суміш UTF-8 і Windows-1251);
- `system("pause")`, `system("cls")`, `chcp 1251` та `SetConsoleCP` замінено на `lab::pause()`, `lab::clear_screen()`, `lab::init_console()` з [common/lab_compat.h](../../common/lab_compat.h);
- Microsoft-специфічні функції (`scanf_s`, `printf_s`, `boolean`, `void main`) замінено стандартним C++;
- логіка в іншому не змінена; місця, де довелося змінити поведінку, позначені в коді `FIX:`.
- У вихідному тесті 25 значень записувалися в замалий буфер; тепер хі-квадрат обчислюється за частотами у п’яти інтервалах.
- Виправлено константу генератора Парка–Міллера: `IQ = 127773` (замість `12773`).

Для перевірки хі-квадрат 25 нормалізованих значень розподілено на п'ять
інтервалів однакової ширини. У прикладі BBS використано прості числа 47 і 59,
біти обчислюються без тимчасових виділень пам'яті (1–20 бітів на число).
